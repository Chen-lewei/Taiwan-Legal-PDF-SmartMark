# SmartMark Pro 刑案電子卷證 · 智慧書籤建立器 📖⚖️

**專為臺灣司法人員（檢察官、法官、律師、書記官）開發的 PDF 智慧書籤腳本。** 能一鍵自動掃描刑案電子卷證、警卷、交通事故卷證，利用正規表達式與邏輯判斷，自動為「供述證據」與「非供述證據」建立結構化書籤，大幅節省閱卷與整理時間。

* **目前版本**：V9.9.30 (執行版)
* **開發者**：檢察官 Chen Le-Wei 
* **最新優化**：加入抗 OCR 亂碼之匯款單據終極擴充盾牌，避免誤建書籤。

## 💻 支援的軟體環境

本腳本原生支援以下 PDF 編輯軟體：
1. **法務部檢察機關數位卷證應用系統 (SR PDFEDIT)**：基於 PDF-XChange 6.0 核心，公務電腦可直接使用。
2. **PDF-XChange Editor (最新版)**：一般律師或司法人員於個人電腦使用的市售版本亦可完美相容。

## ✨ 主要功能

* **✅ 自動分類雙軌制**：精準辨識並分類「📝 供述證據」（如警詢、偵訊筆錄）與「📁 非供述證據」（如診斷證明、相驗證明、匯款紀錄）。
* **✅ 智慧命名與日期擷取**：自動擷取受詢問人姓名、日期、文件類型（例如：`王小明1120106警詢筆錄`、`道路交通事故現場圖`）。
* **✅ 抗亂碼擴充盾牌**：針對品質不佳的掃描檔（OCR 辨識錯誤），內建強大的容錯與正規表達式盾牌（特別強化匯款單、無摺存款等表單的誤判排除）。
* **✅ 同名自動編號防呆**：遇到重複證據名稱會自動加上序號，防止書籤互相覆蓋。

## 📥 快速入門 5 步驟 (使用教學)

只要 10 秒鐘，就能完成過去需要半小時的書籤整理工作！

### STEP 1：開啟卷證檔案
在「法務部數位卷證系統 (SR PDFEDIT)」或「PDF-XChange Editor」中開啟您要處理的 PDF 卷證檔案。
*(⚠️ 注意：請確保該檔案已經過 OCR 文字識別處理)*

### STEP 2：複製腳本
打開本專案的 [`SmartMark.js`](SmartMark.js) 檔案，將裡面的全部程式碼複製到剪貼簿（全選 `Ctrl + A` -> 複製 `Ctrl + C`）。

### STEP 3：呼叫 JavaScript 控制台
回到您的 PDF 軟體畫面，按下鍵盤快捷鍵 **`Ctrl + J`**，此時會彈出「JavaScript 控制台」視窗。

### STEP 4：貼上腳本
在 JavaScript 控制台的「輸入區」（通常在畫面上方或下方空白處），按下 **`Ctrl + V`** 貼上剛剛複製的腳本程式碼。

### STEP 5：執行並建立書籤
點擊控制台上的 **「運行 / 執行 (Run)」**。
* 掃描進度會顯示在控制台日誌中（100-200 頁約需 10-20 秒，請勿關閉視窗）。
* 完成後會彈出對話框提示建立成功。
* 按下 **`Ctrl + B`** 打開書籤面板，即可看到整理好的「📋 智慧書籤清單」。
* 最後記得按下 **`Ctrl + S`** 儲存檔案！

## 📑 支援的自動書籤格式預覽

### 📝 供述證據
涵蓋常見筆錄與紀錄表，自動結合姓名與日期：
* `王小明1120106警詢筆錄` / `調查筆錄` / `廉詢筆錄`
* `林雅芳1121221偵訊筆錄` (被告)
* `證人張志偉1131111偵訊筆錄` (單一證人)
* `證人李小華等2人1140421偵訊筆錄` (多位證人)
* `陳美玲1140225準備程序筆錄` / `審判筆錄`
* `王小明1120106道路交通事故談話紀錄表`

### 📁 非供述證據
支援極為廣泛的物證與書證，包含但不限於：
* **醫療相驗類**：診斷證明書、相驗屍體證明書、法醫研究所解剖暨鑑定報告、成人保護案件通報表。
* **金融詐欺類**：存款交易明細、客戶存款往來交易明細表、受理詐騙帳戶通報警示簡便格式表。
* **交通事故類**：道路交通事故調查報告表(一)(二)、酒精測定紀錄表、肇事人自首情形紀錄表、現場圖、初步分析研判表、行車事故鑑定委員會鑑定意見書。
* **偵查搜扣類**：搜索扣押筆錄、扣押物品目錄表、自願受採尿同意書、刑事案件照片、扣押物品照片。
* **書狀類**：刑事辯護意旨狀、刑事答辯狀、刑事告訴狀。

## 💡 常見問題 (FAQ)

**Q：為什麼有些書籤顯示「未知日期」或「未知對象」？**
> A：通常是因為該頁面的 PDF 掃描品質不佳，導致 OCR（光學字元辨識）無法正確讀取文字。您可以在左側書籤面板直接按右鍵手動重新命名補齊。

**Q：執行時跳出「OCR 品質警告」怎麼辦？**
> A：腳本會在掃描前檢查前 5 頁的文字品質。若發現純圖片比例過高，代表這份卷證可能尚未進行文字辨識。建議先在軟體內執行「識別文字（OCR）」功能後，再重新執行本腳本。

**Q：我不小心執行了兩次，產生重複的書籤怎麼辦？**
> A：請在左側書籤面板找到最上層的「📋 智慧書籤清單」群組，對其點擊右鍵選擇「刪除」。刪除乾淨後，重新執行一次腳本即可。
